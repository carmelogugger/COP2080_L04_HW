# COP2080 - L04 Homework: Letter Grade Average Program

## Description
This Python application:
- Accepts four letter grades separated by `$`
- Converts them to numeric grades on a 4.0 scale
- Drops the lowest grade
- Calculates the average GPA
- Applies a curve if applicable
- Prints a formatted report in an ASCII box

- `grade_compute.py`
- `README.md`
